Open another VS Code terminal.

# STEP 1C — Create the initial backend structure

Inside:

```text
server/
```

create:

```text
server/
│
├── src/
│   ├── controllers/
│   ├── domain/
│   ├── repositories/
│   ├── services/
│   ├── routes/
│   ├── middleware/
│   ├── database/
│   └── app.js
│
├── .env
├── .gitignore
└── package.json
```

This isn't arbitrary folder decoration.

It corresponds to the design we already produced:

| Design concept      | Implementation  |
| ------------------- | --------------- |
| Controller          | `controllers/`  |
| Domain objects      | `domain/`       |
| Repository          | `repositories/` |
| Source processor    | `services/`     |
| API endpoints       | `routes/`       |
| JWT/RBAC later      | `middleware/`   |
| MySQL               | `database/`     |
| Express application | `app.js`        |

And importantly, **we're not going to create every UML class as a JavaScript class just because it appears on the DCD**. Some will become modules, database operations, or plain data structures where that makes more sense.
